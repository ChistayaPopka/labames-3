# Барахолка — доска объявлений на Django

Веб-сервис для размещения и поиска объявлений. Django 6.0, серверные шаблоны (Django Templates), база данных SQLite.

## Возможности

- лента объявлений с поиском, фильтрами (категория, город, цена, состояние), сортировкой и пагинацией;
- страница объявления со счётчиком просмотров и блоком «Похожие»;
- регистрация с подтверждением почты одноразовым кодом, вход и выход;
- создание, редактирование и удаление своих объявлений, загрузка фото;
- снятие объявления с публикации (видно только автору);
- избранное;
- тестовый баланс и бронирование товаров (см. ниже);
- переписка покупателя с продавцом по объявлению (см. ниже);
- админ-панель для категорий, объявлений, кошельков и заказов.

## Запуск

Нужен Python 3.12 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo      # категории и демо-объявления
python manage.py runserver
```

Сайт откроется на http://127.0.0.1:8000/

Команда `seed_demo` создаёт двух демо-пользователей: `anna` и `ivan`, пароль `demo12345`, у каждого 50 000 тестовых ₽.

## Тестовый баланс и бронирование

Деньги ненастоящие: пополнение бесплатное (страница «Кошелёк», кнопки +1000 … +50 000).

1. Покупатель жмёт «Забронировать» на странице объявления — цена **замораживается** на его балансе, объявление пропадает из ленты.
2. Встретились, товар передан — покупатель жмёт «Получил» в разделе «Заказы»: деньги уходят продавцу, объявление снимается с публикации.
3. Покупатель или продавец может отменить бронь — деньги возвращаются покупателю.
4. Бронь держится 48 часов, потом истекает и деньги возвращаются автоматически.

Каждая операция пишется в журнал (история в кошельке). Менять суммы можно только через `wallet/services.py`; в админке баланс доступен только для чтения, а начислить деньги можно действием «Начислить 10 000 / 50 000 тестовых ₽».

Просроченные брони закрываются при открытии объявления или страницы заказов, а также командой (на сервере — по cron, например раз в 10 минут):

```powershell
python manage.py expire_orders
```

Настройки в `config/settings.py`: `WALLET_RESERVATION_HOURS`, `WALLET_TOPUP_MAX`, `WALLET_BALANCE_MAX`.

## Сообщения

- На странице объявления кнопка «Написать продавцу». Диалог создаётся только после первого сообщения; на одно объявление у покупателя один диалог, повторное нажатие открывает его («Перейти к переписке»).
- Раздел «Сообщения» в шапке: все диалоги (покупки и продажи) по времени последнего сообщения, превью, счётчик непрочитанных. Общее число непрочитанных показывается бейджем в шапке.
- В переписке сообщения отправляются без перезагрузки, новые подгружаются раз в 4 секунды (пока вкладка открыта); у своих сообщений ✓ — доставлено, ✓✓ — прочитано. Без JavaScript всё работает обычной отправкой формы.
- Автор видит на странице своего объявления кнопку «Сообщения по объявлению (N)».
- Если объявление удалят, переписка сохранится (заголовок хранится копией). В снятом объявлении написать новому покупателю нельзя, но начатые диалоги продолжаются.

Доступ в админку (http://127.0.0.1:8000/admin/):

```powershell
python manage.py createsuperuser
```

## Регистрация и подтверждение почты

1. Пользователь заполняет форму регистрации — аккаунт создаётся неактивным.
2. На указанную почту уходит 6-значный одноразовый код.
3. После ввода верного кода аккаунт активируется, пользователь входит на сайт.

Правила: код действует 10 минут, на один код даётся 5 попыток, новый код можно запросить раз в 60 секунд (старый при этом перестаёт действовать). В базе хранится только хеш кода. Аккаунт, не подтверждённый в течение часа, удаляется при следующей регистрации, чтобы освободить логин и почту. Если неподтверждённый пользователь пытается войти с верным паролем, его отправляют на страницу ввода кода.

### Отправка писем

По умолчанию письма **печатаются в консоль**, где запущен `runserver`, — код подтверждения нужно взять оттуда. Чтобы отправлять настоящие письма, задайте переменные окружения перед запуском сервера:

```powershell
$env:EMAIL_HOST = "smtp.example.com"
$env:EMAIL_PORT = "587"                 # 587 — STARTTLS, 465 — SSL
$env:EMAIL_HOST_USER = "you@example.com"
$env:EMAIL_HOST_PASSWORD = "пароль-приложения"
$env:DEFAULT_FROM_EMAIL = "you@example.com"
python manage.py runserver
```

## Структура

| Путь | Назначение |
| --- | --- |
| `config/` | настройки проекта и корневые URL |
| `ads/models.py` | модели `Category` и `Ad` |
| `ads/views.py` | представления (class-based views) |
| `ads/forms.py` | формы объявления и фильтра |
| `accounts/` | регистрация, вход, подтверждение почты кодом |
| `wallet/` | тестовый баланс: модели `Wallet`, `Order`, `Transaction`, логика в `services.py` |
| `chat/` | переписка: модели `Conversation`, `Message`, логика в `services.py` |
| `ads/management/commands/seed_demo.py` | наполнение демо-данными |
| `templates/` | HTML-шаблоны |
| `static/css/style.css` | стили |
| `media/` | загруженные фото (создаётся автоматически) |
