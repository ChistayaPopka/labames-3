# Барахолка — доска объявлений на Django

Веб-сервис для размещения и поиска объявлений. Django 6.0, серверные шаблоны (Django Templates), база данных SQLite.

## Возможности

- лента объявлений с поиском, фильтрами (категория, город, цена, состояние), сортировкой и пагинацией;
- страница объявления со счётчиком просмотров и блоком «Похожие»;
- регистрация с подтверждением почты одноразовым кодом, вход и выход;
- создание, редактирование и удаление своих объявлений, загрузка фото;
- снятие объявления с публикации (видно только автору);
- избранное;
- админ-панель для категорий и объявлений.

## Запуск

Нужен Python 3.12 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo      # категории и демо-объявления
python manage.py runserver
```

Сайт откроется на http://127.0.0.1:8000/

Команда `seed_demo` создаёт двух демо-пользователей: `anna` и `ivan`, пароль `demo12345`.

Доступ в админку (http://127.0.0.1:8000/admin/):

```powershell
python manage.py createsuperuser
```

## Регистрация и подтверждение почты

1. Пользователь заполняет форму регистрации — аккаунт создаётся неактивным.
2. На указанную почту уходит 6-значный одноразовый код.
3. После ввода верного кода аккаунт активируется, пользователь входит на сайт.

Правила: код действует 10 минут, на один код даётся 5 попыток, новый код можно запросить раз в 60 секунд (старый при этом перестаёт действовать). В базе хранится только хеш кода. Аккаунт, не подтверждённый в течение часа, удаляется при следующей регистрации, чтобы освободить логин и почту. Если неподтверждённый пользователь пытается войти с верным паролем, его отправляют на страницу ввода кода.

### Отправка писем

По умолчанию письма **печатаются в консоль**, где запущен `runserver`, — код подтверждения нужно взять оттуда. Чтобы отправлять настоящие письма, задайте переменные окружения перед запуском сервера:

```powershell
$env:EMAIL_HOST = "smtp.example.com"
$env:EMAIL_PORT = "587"                 # 587 — STARTTLS, 465 — SSL
$env:EMAIL_HOST_USER = "you@example.com"
$env:EMAIL_HOST_PASSWORD = "пароль-приложения"
$env:DEFAULT_FROM_EMAIL = "you@example.com"
python manage.py runserver
```

## Структура

| Путь | Назначение |
| --- | --- |
| `config/` | настройки проекта и корневые URL |
| `ads/models.py` | модели `Category` и `Ad` |
| `ads/views.py` | представления (class-based views) |
| `ads/forms.py` | формы объявления и фильтра |
| `accounts/` | регистрация, вход, подтверждение почты кодом |
| `ads/management/commands/seed_demo.py` | наполнение демо-данными |
| `templates/` | HTML-шаблоны |
| `static/css/style.css` | стили |
| `media/` | загруженные фото (создаётся автоматически) |
